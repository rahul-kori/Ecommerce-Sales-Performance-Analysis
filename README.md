# E-commerce Sales Performance Analysis

## Project Overview
This project analyzes an E-commerce dataset to understand sales performance, customer behaviour, and delivery efficiency.

The analysis was performed using SQL, Python, and Power BI.

## Dataset
Brazilian E-commerce dataset containing 100K+ orders from 2016–2018.

## Tools Used
SQL Server
Python (Pandas, Matplotlib, Seaborn)
Power BI

## Key Analysis
• Revenue analysis
• Product performance
• Customer location analysis
• Payment method analysis
• Delivery performance

## Dashboard
The Power BI dashboard visualizes key KPIs such as:
Total Revenue
Total Orders
Average Order Value
Top Product Categories

## Key Insights
• beleza_saude category generated highest revenue
• Credit card is the most used payment method
• Sales peak during August month
• Average delivery time is approximately 12 days
